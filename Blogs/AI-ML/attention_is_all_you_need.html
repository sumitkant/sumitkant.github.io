What I Learned from “Attention Is All You Need”

A first-principles walkthrough of why the Transformer replaced recurrence, how attention actually works, what the famous complexity table means, and how to interpret the paper’s perplexity, BLEU and parsing F1 results.

TransformerSelf-attentionMachine translationConstituency parsing
01 · The problem

Why replace recurrence at all?

Before the Transformer, strong sequence models were usually RNNs, LSTMs or GRUs. Their main weakness was not that they could not model language; it was that they had to process a sequence step by step.

\[h_t=f(h_{t-1},x_t)\]

That dependency means token 5 cannot be processed until token 4 has produced its hidden state. Even on a GPU, much of the sequence computation therefore remains sequential.

RNN information flow
x₁ → h₁ → h₂ → h₃ → … → hₙ

Convolutional sequence models improved parallelism, but a local convolution still needs several layers before two distant tokens can influence one another.

The Transformer’s core bet: instead of passing information through a chain, let every token directly decide which other tokens matter to it.

The architecture shift is from sequential state propagation to direct token-to-token communication.

02 · Architecture

The Transformer at a glance

The model is still an encoder–decoder. The encoder turns input tokens into contextual representations. The decoder then generates the output sequence autoregressively.

Encoder6 identical layers. Each layer contains multi-head self-attention and a position-wise feed-forward network.
Decoder6 layers. Each adds masked self-attention, encoder–decoder attention and a feed-forward network.

Every sub-layer is wrapped by a residual connection and layer normalization:

\[\mathrm{LayerNorm}(x+\mathrm{Sublayer}(x))\]

For the base model, the residual-stream dimension is 512. The feed-forward block expands each position from 512 → 2048 → 512.

03 · Core operation

Attention from first principles

For each token, the model creates three learned representations: a query, a key and a value.

QueryWhat information am I looking for?
KeyWhat kind of information do I contain?
ValueWhat information should I pass if I am relevant?
\[\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V\]

Read the equation as a five-step process

  1. Create Q, K and V vectors for every token.
  2. Compute all query–key similarity scores with \(QK^T\).
  3. Scale the scores by \(\sqrt{d_k}\).
  4. Apply softmax so each row becomes a distribution of attention weights.
  5. Use those weights to take a weighted combination of the value vectors.
Why scale by \(\sqrt{d_k}\)? Dot products tend to grow in magnitude as the vector dimension grows. Large values can push softmax into saturated regions and make gradients tiny. Scaling keeps the score range better behaved.
04 · Multiple views

Why use multiple attention heads?

A single attention distribution has to compress every useful relationship into one weighted average. Multi-head attention gives the model several learned projection spaces in parallel.

\[\mathrm{head}_i=\mathrm{Attention}(QW_i^Q,KW_i^K,VW_i^V)\]
\[\mathrm{MultiHead}(Q,K,V)=\mathrm{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)W^O\]

The base Transformer uses 8 heads with \(d_{model}=512\), so each head works in a 64-dimensional projected space:

\[512/8=64\]

Different heads can learn different kinds of relationships—local phrase structure, long-range dependencies, syntactic relations or reference patterns. The appendix visualizations show that different heads indeed attend to different structures.

Three places attention appears: encoder self-attention, masked decoder self-attention, and encoder–decoder cross-attention.
05 · Order

Attention alone does not know token order

Self-attention can compare token representations, but by itself it has no built-in notion that one token came before another. The model therefore adds a positional vector to every token embedding.

\[\mathrm{InputRepresentation}=\mathrm{TokenEmbedding}+\mathrm{PositionalEncoding}\]

The paper uses sinusoidal functions at different frequencies:

\[PE_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)\]
\[PE_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)\]

These give each position a deterministic pattern. The authors also tried learned position embeddings and reported almost identical translation quality in their experiment.

Attention tells the model what relates to what; positional encoding tells it where each token sits.

06 · The famous comparison

What Table 1 is really saying

Table 1 is not an accuracy table. It compares four layer types on three architectural properties: computational cost, sequential depth and the number of hops needed for distant positions to communicate.

Question I had while reading: “I did not understand Table 1. Help me understand from scratch.”

Sequential operations asks how many computation stages must wait for previous stages. An RNN has roughly \(n\); self-attention can compute all pairwise scores together, so it has constant sequential depth with respect to sequence length.

Maximum path length asks how many computational hops are needed for one token to influence another. In an RNN, two distant positions may require \(O(n)\) hops. In full self-attention, token 1 can directly attend to token \(n\) in one layer: \(O(1)\).

The trade-off: that direct global access requires an \(n\times n\) attention matrix, which creates the quadratic \(n^2\) term.

Why self-attention can be cheaper than recurrence

Compare \(n^2d\) with \(nd^2\). Cancel \(nd\), and self-attention is cheaper in this simplified comparison when:

\[n<d\]

For \(n=100\) and \(d=512\): self-attention is about 5.12 million operations by the simplified term, versus about 26.2 million for recurrence—roughly 5.1× lower.

The win is not “attention is always cheaper.” The win is parallelism + constant path length, with quadratic sequence-length cost as the trade-off.

07 · Training recipe

How the original Transformer was trained

4.5MEN→DE pairsWMT 2014 English–German.
36MEN→FR pairsWMT 2014 English–French.
8×NVIDIA P100Training hardware.

The English–German experiment used a shared BPE vocabulary of roughly 37K tokens. Batches contained approximately 25K source tokens + 25K target tokens.

Optimization

Adam was used with \(\beta_1=0.9\), \(\beta_2=0.98\), and \(\epsilon=10^{-9}\). The learning rate warmed up for 4,000 steps, then decayed approximately with the inverse square root of the step number.

\[\mathrm{lrate}=d_{model}^{-0.5}\min(\mathrm{step}^{-0.5},\mathrm{step}\cdot\mathrm{warmup}^{-1.5})\]

The base model trained for about 100K steps / 12 hours. The big model trained for about 300K steps / 3.5 days.

Regularization

The base model used 0.1 dropout and 0.1 label smoothing. A useful subtlety: label smoothing can improve BLEU and accuracy while making perplexity worse, because the model is deliberately discouraged from becoming maximally confident in the target label.

BLEU measures overlap between generated translations and reference translations using n-gram matching and a brevity penalty. Higher is better. The paper’s important claim was not only strong translation quality, but strong quality with substantially less training computation than several previous systems listed in the comparison.

Question I had while reading: “What is perplexity on page 9?”

Perplexity is a transformation of average cross-entropy loss:

\[\mathrm{PPL}=e^{\mathrm{cross\ entropy}}\]

Lower is better. A loose intuition is the model’s effective number of plausible next-token choices. So 4.33 is better than 4.92, although the model is not literally choosing uniformly among 4.33 tokens.

These are per-wordpiece perplexities, so they should not be directly compared with word-level perplexities produced under a different tokenization scheme.

09 · Beyond translation

Why the parsing experiment mattered

The paper also applied the Transformer to English constituency parsing. This is a structured prediction task: given a sentence, predict a tree describing grammatical constituents such as noun phrases and verb phrases.

Example gold parse structure
(S
  (NP (DT The) (NN cat))
  (VP (VBD sat)
      (PP (IN on)
          (NP (DT the) (NN mat)))))
Training setupWSJ Section 23 F1
Transformer, WSJ only91.3

Best result listed in the paper table93.3
Question I had while reading: “What is F1 score in Table 4?”

F1 measures how well the predicted parse tree recovers the constituents in the gold tree.

\[P=\frac{\text{correct predicted constituents}}{\text{all predicted constituents}},\quad R=\frac{\text{correct predicted constituents}}{\text{all gold constituents}}\]
\[F1=2\frac{PR}{P+R}\]

If the gold tree contains 100 constituents, the model predicts 95, and 90 are correct, precision is 94.7%, recall is 90%, and F1 is about 92.3.

Question I had while reading: “How do you prepare this ground-truth structure? Is it already in a dataset?”

Yes. The experiment uses the Penn Treebank, a pre-existing manually annotated linguistic dataset. The paper does not build the gold trees from scratch.

  1. Start with raw sentences, largely from Wall Street Journal text.
  2. Assign part-of-speech labels and phrase-structure annotations.
  3. Human annotators create and/or correct parse trees under a common guideline.
  4. Run quality-control and consistency checks.
  5. Split the treebank into train, development and test sections.

For this experiment, WSJ Section 22 was used for development and Section 23 for final evaluation. The WSJ-only training set contains roughly 40K sentences.

10 · What was actually new

The breakthrough was the architecture, not a single ingredient

Encoder–decoder models already existed. Attention already existed. Residual connections, layer normalization and feed-forward networks already existed. Positional representations also had precedent.

The important step was combining these ideas into a practical sequence model where attention replaces recurrent and convolutional sequence-processing layers, then showing that the design was both computationally attractive and empirically strong.

The design question changed: from “How do we build a better recurrent sequence model?” to “How far can we scale and improve attention-based models?”
11 · Memory aid

The numbers and ideas worth remembering

Base Transformer6 encoder + 6 decoder layers; \(d_{model}=512\); 8 heads; \(d_k=d_v=64\); \(d_{ff}=2048\); ~65M parameters.
Big Transformer\(d_{model}=1024\); 16 heads; \(d_{ff}=4096\); ~213M parameters; dev PPL 4.33; dev BLEU 26.4.

Five ideas to keep

  1. Self-attention lets every token directly gather information from other tokens.
  2. Queries and keys determine relevance; values carry the information being aggregated.
  3. Multi-head attention gives the model several learned relationship spaces in parallel.
  4. Positional encoding is necessary because attention alone does not encode order.
  5. The Transformer trades the RNN’s sequential path for highly parallel computation with quadratic token-pair interactions.

The simplest mental model: every token repeatedly asks the rest of the sequence, “What information should I pull from you?”
